# Walsh-PCE Rebuild

Clean and reproducible reconstruction of the experiments reported in the Walsh-PCE MaxCut manuscript.

Pipeline:

1. Random graph bank
2. Hyperparameter calibration
3. Complete Walsh basis
4. Support-reduction sweep
5. Gset benchmark
6. Quantum transfer
7. Hardware validation

All official results must be generated by scripts under `stages/`.
Shared scientific implementations must live under `src/walsh_pce/`.
Notebooks are not authoritative sources of results.

## Reproducibility

See [REPRODUCIBILITY.md](REPRODUCIBILITY.md) for the research protocol, exact stage commands, dataset SHA-256 checks, published-value checks, and known limitations.

The original mathematical implementations under `src/` have not been modified in the portability package.

## Setup

Run `bash scripts/setup.sh` from the repository root; see `REPRODUCIBILITY.md` for prerequisites, version limitations, and the execution sequence.
